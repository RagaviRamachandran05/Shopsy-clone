# Shopsy - React e-commerce store

React 18 + Vite + React Router + TanStack Query + Bootstrap 5 + custom CSS. Data from DummyJSON.

## Run
    npm install
    npm run dev

## Features
- Live search (debounced), category chips, sorting, "show more" pagination
- Product details with image gallery, stock status, reviews
- Cart (Context + useReducer), quantity controls, free-delivery progress, saved in localStorage
- Loading skeletons, error + empty states, toast feedback, responsive, keyboard-focus styles

## Deploy
`npm run build`, then push to GitHub and import into Vercel or Netlify.
